# 06 — Financials & Pricing

A framework, not real numbers — fill in your figures. The goal is a credible investment-vs-revenue story with a staged, low-risk spend profile.

## Investment (cost categories)
| Category | Type | Notes |
|----------|------|-------|
| NDR platform (pilot/lab) | Capex/one-time | Pilot sensors + licences; small to start |
| Platform (production, MSSP) | Opex | Scales with clients/sensors; often partner-subsidized in ramp |
| Training & certification | One-time/recurring | GICSP, SANS ICS410/515, vendor academies for the nucleus |
| Anchor hire(s) | Opex | 1–2 experienced OT staff |
| SIEM/SOAR integration effort | One-time | Mostly internal effort (reuse existing platform) |
| Detection content build | One-time | Accelerated by prebuilt libraries |
| Go-to-market / enablement | One-time | Collateral, sales enablement |

**Staged spend:** Phase 0–1 are cheap (mostly effort); the meaningful spend (platform, hires) comes at the Phase 1 gate; production scale-up is demand-driven. This protects the P&L — you only commit big after the pilot proves it.

## Pricing models (choose per service)
| Model | Fits | Notes |
|-------|------|-------|
| **Recurring MSS subscription** (per site / per sensor / per asset) | Core run service | Predictable ARR; align unit to NDR licensing |
| **Fixed-price onboarding project + recurring MSS** | Most engagements | Deploy/detect as project; monitor as subscription |
| **Tiered (Essential/Advanced/Safety-critical)** | Productized offering | Upsell path built in |
| **T&M / capped** | Assessment phase | Fixed-price the rest after scoping |

Premium positioning is justified by scarcity and consequence — OT MDR is specialized; don't price it like commodity IT monitoring.

## Revenue ramp (illustrative shape)
- Pilot (1 lighthouse) → first paying client(s) at launch → steady onboarding as pipeline matures.
- Model conservative / expected / stretch scenarios; show break-even against the staged investment.
- Highlight **account expansion** — existing IT clients with OT exposure are the fastest pipeline.

## The financial narrative
> Staged investment, most of it deferred until a low-cost pilot proves the capability; premium recurring revenue from a scarce, in-demand service; and expansion into the existing client base. The downside is capped by the pilot gate; the upside is a differentiated ARR stream and larger convergence deals.
