# 05 — Implementation Plan

A phased, low-risk plan with a decision gate after the pilot — so the big investment is conditional on proven results. This is what makes leadership's "yes" easy.

```
  PHASE 0        PHASE 1         PHASE 2            PHASE 3          PHASE 4
  Assess    ──▶  Define     ──▶  Build & Pilot ──▶ [GATE] ──▶ Launch ──▶ Scale
  4 lenses       service/        platform, skills,   go/no-go  productize   grow clients,
  current-state  platform,       lighthouse pilot    decision  & GTM        add tiers
                 business case
```

## Phase 0 — Assess (2–4 weeks)
Run the discovery (`02`); score the four lenses; validate demand with sales/clients.
Deliverables: current-state assessment · demand validation · draft business case.
Gate: leadership agrees to fund Define.

## Phase 1 — Define (3–5 weeks)
Finalize service tiers, delivery model, SLAs (`03`); select the NDR platform & partnership; skills plan (`04`); financials & pricing (`06`); pilot plan (`07`).
Deliverables: service definition · platform decision · skills plan · business case v1 · pilot plan.
Gate: approval to invest in platform + pilot.

## Phase 2 — Build & Pilot (8–12 weeks)
Stand up the platform (MSSP tenancy), integrate to SIEM, train the nucleus, and run a **lighthouse pilot** on an internal lab or one friendly client (`07`). Build the core detection content and playbooks.
Deliverables: working platform + SIEM integration · trained nucleus · pilot results · reference detection content & playbooks · case study.
**Gate (the important one):** pilot success criteria met → go/no-go to launch.

## Phase 3 — Launch (4–6 weeks)
Productize: service catalog, pricing, onboarding runbooks, SLAs, marketing/sales enablement. Enable pre-sales.
Deliverables: productized service · sales enablement · onboarding runbook · first client(s) in pipeline.

## Phase 4 — Scale (ongoing)
Onboard clients, add tiers (Advanced, Safety-critical), grow the team with demand, run detection lifecycle & threat hunting, report KPIs.

## Indicative timeline
| Phase | Duration | Cumulative |
|-------|----------|-----------|
| Assess | 2–4 wks | ~1 mo |
| Define | 3–5 wks | ~2 mo |
| Build & Pilot | 8–12 wks | ~4–5 mo |
| Launch | 4–6 wks | ~5–6 mo |
| Scale | ongoing | — |

~5–6 months from start to a launched, pilot-proven service. Adjust to your procurement and hiring speed.
