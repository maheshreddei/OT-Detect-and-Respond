|----------|-------|

## What it is
The TCP profile of IEC 60870-5, used widely in electric power and utility SCADA for telecontrol between control centres and substations. Data is organized as **ASDUs** (Application Service Data Units) addressed to **IOAs** (Information Object Addresses); a **Cause of Transmission (COT)** describes why each message was sent.

## What it really means for a defender
IEC-104 cleanly separates **monitor** ASDUs (the station reporting measurements/states — recon fodder) from **command** ASDUs (the master operating something — impact). The range's "command IOA" is exactly this: a control ASDU (single/double command, setpoint) sent to a specific IOA to operate a breaker, switch, or setpoint. For a defender the rule is crisp: **command ASDUs should originate only from the legitimate master(s)**; a control command from anywhere else, or an interrogation/clock-sync from an unexpected source, is your signal. Because it's power-sector telecontrol, an unauthorized command can mean opening a breaker.

## Attacker actions (recon → impact)
- **Discover:** connect on TCP/2404; issue interrogation (C_IC, type 100) to dump the full point list — instant process map.
- **Read (recon):** collect monitor ASDUs (measurements, statuses).
- **Command (impact):** send control ASDUs to a command IOA — single command (C_SC, 45), double command (C_DC, 46), regulating step (C_RC, 47), setpoint (C_SE, 48–50). This operates the process.
- **Disrupt:** clock sync (C_CS, 103) manipulation; reset process (C_RP, 105).

## Detections you can build
| Detection | Signal / logic | Log source | ATT&CK ICS |
|-----------|----------------|------------|------------|
| Command ASDU from non-master | C_SC/C_DC/C_RC/C_SE from a host outside the master baseline | `iec104.log` | T0855 Unauthorized Command Message, T0831 |
| Setpoint command | C_SE (48–50) to a command IOA | `iec104.log` | T0836 Modify Parameter |
| Interrogation recon | C_IC (100) from unexpected source | `iec104.log` | T0846, T0888 |
| Command to critical IOA | Control ASDU to a breaker/safety IOA | `iec104.log` + IOA map | T0855, T0832 |
| Clock-sync / reset abuse | C_CS (103) / C_RP (105) anomalies | `iec104.log` | T0837, T0814 |
| New IEC-104 client | First-time source speaking 104 | NDR + baseline | T0855 |
| Cross-zone 104 | TCP/2404 outside the SCADA zone | firewall/NDR | T0885 |

## Log sources & telemetry
ICSNPP `iec104.log` exposes ASDU type id, COT, common address, and IOA — the exact fields you need to separate monitor from command and to pin the target IOA. NDRs carry IEC-104 command policies. pcap + IOA map confirm which point was operated; historian confirms the physical effect (breaker/switch state).

## Functions/services to watch
**Monitor (recon):** M_SP/M_DP/M_ME (types 1–40). **Command (impact):** C_SC (45), C_DC (46), C_RC (47), C_SE (48–50). **System:** C_IC (100, interrogation), C_CS (103, clock), C_RP (105, reset). Watch COT values that indicate activation of commands.

## ATT&CK mapping
T0855 Unauthorized Command Message · T0831 Manipulation of Control · T0836 Modify Parameter · T0832 Manipulation of View · T0846 Remote System Discovery · T0814 Denial of Service.
